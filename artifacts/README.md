# BetterOptions 0.2 — the binary, kept because its source is lost

This is the app that ran on Mark's Mac from 2026-03-27 until 2026-08-13, and is running
again now. **Its source code no longer exists anywhere.** It was written between the
2026-03-23 backup and the 2026-03-27 build, was never committed, and the folder it lived
in was deleted before the next backup on 2026-06-08.

Searched and came up empty on 2026-08-13: every folder on the Mac, the Trash, iCloud,
both Google Drive accounts, the external drives 970 and pt2, all Time Machine backups
covering the window, both GitHub accounts (aicoder88 and Dgcode88), and the local agent
session records.

One thing did survive: a `git status` inside a 2026-04-26 session lists the five source
files 0.2 added on top of 0.1, all of them still untracked at that date —
`DeviceRegistry.swift`, `SettingsStore.swift`, `SettingsView.swift`,
`SettingsWindowController.swift`, `SystemActionSender.swift`.

What the binary does is written up in `docs/recovered-v0.2-features.md`. The plan to
rebuild it is in `docs/plans/gvoice-remap-onto-v0.2.md`.

**Do not delete this folder.** It is the only copy of 0.2 outside Mark's Mac.
